# medinexa-hospital-management (HospitalCare Enterprise System)

## 🏥 HospitalCare Enterprise Management System

A Java Enterprise (JSP/Servlet/Tomcat 11/MySQL) Hospital Management System featuring an interactive **Python Streamlit Cloud AI Dashboard (`streamlit_app.py`)**.

---

## 🚀 How to Deploy on Streamlit Cloud

1. Push your repository to **GitHub**: `ShubhamShinde228/medinexa-hospital-management`
2. Go to **[Streamlit Cloud](https://share.streamlit.io)** and log in.
3. Click **"New App"** ➔ Select your GitHub repository: `ShubhamShinde228/medinexa-hospital-management`
4. Set Main file path: **`streamlit_app.py`**
5. Click **Deploy!** 🚀

Streamlit Cloud will automatically detect `streamlit_app.py` and `requirements.txt` to launch the live platform!

---

## 🌟 Key Features Included

- **📊 Executive Command Center:** Real-time patient telemetry & bed availability charts.
- **🧠 AI Differential Diagnosis Matrix:** Clinical DDx probability heatmap with Red-Flag emergency ICU escalation alerts.
- **💊 AI Drug-Drug Interaction Safety Engine:** Clinical Decision Support System (CDSS) for conflicting drug pairs.
- **🩸 Smart Blood Bank & Donor Match:** Live 8-blood group inventory grid & universal donor compatibility matcher.
- **📈 Epidemic Outbreak Radar:** Public health disease surveillance trends.
- **🚑 Emergency SOS Ambulance Dispatch:** Paramedic dispatch tracker.
- **💳 Upfront Cost Estimator & Insurance Claim Verifier:** Treatment cost calculator & auto-claim verifier.
- **☕ Java Servlet / Tomcat 11 WAR Backend:** Full Maven enterprise web application (`Hospital_System.war`).
